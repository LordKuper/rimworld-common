Frameworks / libraries

Two acquisition models coexist. Harmony is a NuGet package referenced compile-only (it is excluded from runtime output and must be provided by the host environment at load time). RimWorld and Unity assemblies are game-provided file references resolved from the local install ($(RimWorldManagedDir)) and are never pulled from NuGet.

NameVersionProviderPurpose
Lib.Harmony 2.4.2 NuGet (compile-only) Runtime patching of RimWorld methods. PrivateAssets=all, ExcludeAssets=runtime — compiled against but excluded from output; the host (RimWorld + HarmonyMod / loader) supplies the assembly at runtime.
Assembly-CSharp (RimWorld / Verse) 1.5 + 1.6 game-provided ref The RimWorld game assembly. Core domain types (Pawn, Def, StatDef, ThingDef) and Verse infrastructure the library wraps. File reference, Private=False.
UnityEngine.CoreModule install-resolved game-provided ref Core Unity types (Rect, Color, Texture2D, Mathf) used by helpers and UI. File reference, Private=False.
UnityEngine.IMGUIModule install-resolved game-provided ref Immediate-mode GUI (GUI, GUILayout, GUIStyle) underpinning the widget toolkit in Source/UI/**. File reference, Private=False.
UnityEngine.TextRenderingModule install-resolved game-provided ref Font / text rendering (TextAnchor, Font) for labels and field rendering. File reference, Private=False.

Unity module versions are resolved from the local RimWorld install at build time and are not pinned in source; they track whichever Unity build ships with the targeted RimWorld version.

Constraints

  • Locked to net472 to match the RimWorld runtime; newer target frameworks the game does not load cannot be adopted.
  • Builds require a local RimWorld install: game-managed assemblies (Assembly-CSharp, UnityEngine modules) resolve from $(RimWorldManagedDir) and are never sourced from NuGet.
  • Harmony is compile-only (PrivateAssets=all, ExcludeAssets=runtime) — it is excluded from output and the host environment must provide it at load time.
  • Both RimWorld 1.5 and 1.6 are active supported targets via version-specific folders; per-version assemblies ship under version-named directories (1.5/, 1.6/) and the build emits into the matching <version>/Assemblies/. New versions are onboarded by adding a folder, not by breaking existing ones.
  • Warnings-as-errors at maximum warning level (9999) on Debug and Release — code must stay clean to compile.
  • No NuGet runtime dependencies ship with the library: the only NuGet package (Harmony) is excluded from output, so the assembly carries no third-party runtime payload.
